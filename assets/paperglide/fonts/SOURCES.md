# Paper Glide font asset

`NotoSans-Cyrillic.subset.woff2` is a compact WOFF2 subset of Noto Sans Regular
for the project's answer text. It contains Cyrillic U+0400–U+052F, Latin and
extended Latin U+0000–U+024F, combining marks, and common punctuation. It is
licensed under SIL Open Font License 1.1; see `NotoSans-OFL.txt`.

The subset is used as the final fallback after the shared Noto Sans SC font so
Russian vocabulary and accented Spanish answers render in the bundled UI without
relying on system fonts.
